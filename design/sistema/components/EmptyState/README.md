Bloque arena que explica por qué no hay nada que mostrar y qué puede hacer la persona.

Quien lo usa aporta `title` (una frase corta) y `text` (una o dos frases con la salida), y debajo van los `Button` de las acciones.

- Fondo `surface-sand`, esquinas `radius-xl`, título `title-lg` y texto `body` en `ink-muted`.
- Sirve para «No tiene citas este día», «Sin horas libres» y «Sin conexión».
- Hazlo así: di qué pasó y qué hacer; no culpes a la persona.
- Evítalo: usar terracota; ese color se reserva para la cita principal de la pantalla.
