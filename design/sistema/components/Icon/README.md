Icono de trazo de 24×24 que hereda el color del texto que lo rodea.

Recibe `name` (`phone`, `chat`, `plus`, `check`, `x`, `calendar-check`, `calendar-week`, `users`, `clock`) y opcionalmente `size` (22 por defecto; 24 en la barra inferior).

- Úsalo siempre junto a una palabra visible o dentro de un `IconButton` con `label`. El icono es decorativo para lectores de pantalla.
- El color lo da el contenedor (`brand-deep`, `ink`, `success`), nunca el icono.
- No añadas emojis ni iconos de otra librería; si falta uno, se agrega aquí con el mismo trazo.
