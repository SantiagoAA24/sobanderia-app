Casilla grande con una frase, para el consentimiento de datos personales (Ley 1581 de 2012).

Quien lo usa aporta `label`, opcionalmente `linkText` (el «Ver política» subrayado), `checked` y `onChange` (o `defaultChecked`), y `error` si no se aceptó.

- La casilla mide 28px y la fila al menos 48px; toda la frase es tocable.
- Con `error`, el mensaje aparece debajo en `brand-deep` y negrita.
- Hazlo así: una sola casilla por pantalla y una frase corta y clara.
- Evítalo: casillas premarcadas para consentimientos que la persona deba decidir.
