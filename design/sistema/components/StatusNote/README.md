Línea corta con icono y texto en verde para un resumen o un estado positivo, como "2 citas atendidas hoy".

Quien lo usa aporta el texto (`children`) y, si quiere, otro `icon` (por defecto `check`).

- Color `success` sobre `surface-100`; siempre con palabra e icono.
- Para cancelada o no asistió, usa `icon="x"`; el texto sigue siendo una palabra clara.
- Evítalo: usarlo como botón; no es interactivo.
