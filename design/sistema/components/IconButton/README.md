Botón circular de 48px con un solo icono, para acciones rápidas dentro de una fila.

Quien lo usa aporta el `icon`, el `label` (obligatorio, se lee en voz alta: "Llamar a Hernán Castaño") y `onClick`.

- Úsalo en una fila de agenda para llamar al cliente. Fondo `surface-sand`, icono `brand-deep`.
- Hazlo así: un `label` que incluya el nombre de la persona.
- Evítalo: acciones que no se entienden solo con el icono, o varios botones de icono juntos; si la acción necesita palabra, usa `Button`.
