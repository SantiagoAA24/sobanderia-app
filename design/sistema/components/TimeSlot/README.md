Botón de una hora libre, con la hora grande y "a. m." o "p. m." debajo.

Quien lo usa aporta `time` ("10:30"), `meridiem` ("a. m."), `selected` y `onClick`.

- Va en una cuadrícula de tres columnas con `space-10` de separación, agrupada bajo encabezados `section-title` como "Mañana" y "Tarde".
- La hora elegida se marca con `surface-clay-tint` y borde `brand-deep` de 2px; solo una elegida a la vez.
- Mide al menos 60px de alto.
- Hazlo así: muestra solo los cupos libres.
- Evítalo: mostrar horas ocupadas como botones; si hace falta, se omiten.
